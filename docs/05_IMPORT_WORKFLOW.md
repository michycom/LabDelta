# Import Workflow

1. Select or create patient.
2. Start import from that patient context.
3. Select file.
4. Hash and duplicate check.
5. Extract report metadata and identity.
6. Compare extracted identity with selected patient.
7. Block mismatch or ambiguity.
8. Parse values.
9. Review and correct uncertain fields.
10. Confirm.
11. Persist source and structured data transactionally.
12. Recalculate dashboard.

Never invent missing values, intervals, unit conversions, or parameter mappings.
