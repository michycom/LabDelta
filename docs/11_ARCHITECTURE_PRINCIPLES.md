# Architecture Principles

1. Frozen scope.
2. No diagnosis or recommendation functionality.
3. No runtime cloud dependency.
4. Every displayed value links to source provenance.
5. Raw imports remain immutable.
6. No silent assumptions.
7. Deterministic analysis.
8. Business logic exists once.
9. Strong typing and explicit errors.
10. Migrations from the first implementation.
11. Small coherent modules.
12. Tests accompany every stage.
13. Sequential implementation and commits.
14. Preserve a working partial stage before continuing.
