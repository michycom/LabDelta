# Vision

LabDelta helps medical professionals perceive information already present in laboratory reports.

## Core value

- current values outside the supplied reference interval;
- changes since the immediately preceding comparable result;
- longer-term tendencies;
- overlapping functional laboratory profiles;
- direct traceability to original reports.

## Boundaries

No diagnosis, disease probability, causal claim, treatment recommendation, additional-test recommendation, runtime AI, telemetry, or patient-data upload.
