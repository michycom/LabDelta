# Product Specification

## Frozen MVP

1. Cross-platform local desktop application.
2. Global dashboard across patients, sorted by the most important changes.
3. Expandable severe cases showing multiple affected parameters and profiles.
4. Patient workspace with current status, prior comparison, reference position, and longitudinal tendency.
5. CSV, JSON, and selectable-text PDF import.
6. Unified local database.
7. Overlapping functional laboratory profiles.
8. Original report access and provenance.
9. Manual and automatic patient identity double-check before persistence.
10. Synthetic demonstration data.
11. Fully local operation.
12. No diagnosis or recommendations.

## Global dashboard

The dashboard answers: **Which patients currently have the most important laboratory changes requiring review?**

Each value appears once, with all profile tags. Severe patient cases may expand to several parameter rows.

## Patient workspace

Shows current abnormalities, marked changes, longer-term tendencies, profile aggregation, all reports, and source documents.

## Required wording

Use factual descriptions such as “outside supplied reference interval,” “risen since preceding comparable report,” “lower third of supplied interval,” and “insufficient comparison data.”
