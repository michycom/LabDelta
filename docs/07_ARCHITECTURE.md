# Architecture

## Stack

Tauri 2, React, TypeScript, Rust, SQLite, Vite.

## Rust core

Persistence, migrations, source storage, hashing, import, identity matching, parameter mapping, unit compatibility, classifications, comparisons, trends, profiles, demo generation.

## TypeScript UI

Dashboard, patient workspace, import review, charts, source viewer, settings, errors and empty states.

Business logic exists once in Rust. Runtime operation is local and offline.
