# Three-Minute Demo Script

0:00 Problem: isolated reports hide longitudinal changes.

0:20 Global dashboard: patients ordered by important changes; expand a severe multi-parameter case.

0:45 Patient workspace: current value, prior value, delta, interval position, short-term direction, long-term tendency.

1:20 Profiles: overlapping organizational membership and transparent counts.

1:45 Source: open original report from a historical point.

2:05 Import: preselect patient, compare extracted identity, block mismatch, confirm valid report.

2:35 Privacy: local, deterministic, no runtime AI, no diagnosis or recommendation.

2:50 Planned open-source direction and Codex: repository, staged commits, tests, cross-platform workflow.
